# Contributing

Contributions that can change the mathematical standing of a claim are especially welcome: counterexamples, proof gaps, failed reproductions, convention mismatches, independent derivations, and prior-art identifications.

## Before opening a contribution

- Identify the permanent claim ID.
- Quote the exact statement or file region being challenged.
- Distinguish a mathematical objection from a software or presentation issue.
- Provide the smallest reproducible witness available.
- State any coefficient, grading, orientation, filtration, or coordinate convention on which the objection depends.

Use the corresponding structured issue form when possible. A pull request that changes a claim must also update its `CLAIM.json`, README standing, and revision record.

Acceptance into this repository records a bounded contribution. It does not imply agreement with unrelated CBMD research or confer authorship, endorsement, or canonical standing beyond the accepted change.
