# Revisions

| Version | Note |
|---|---|
| 0.1.0 | First publication: the star correspondence compiled (reachable states are bin runs, bin runs are exact-bin block decompositions), hence strong NP-hardness of reaching the normal form from a fixed state via 3-PARTITION; census against exact simulation; semantics custody against the weighted dossier. |
| 0.2.0 | Getting stuck on the star: compiled `fill_eq_mod`, `stuck_imp_witness`, `safe_of_no_witness` (a stuck run yields a residue witness; no witness certifies safety); written O(kB) residue decider; the converse stated as a conjecture with exhaustive evidence (B <= 13, k <= 8, 500,461 instances, no counterexample); an extremal proof route recorded as failing in range; the sharper largest-fit form of the conjecture recorded as holding throughout; a two-receiver system showing the residue condition is necessary but not sufficient beyond the star. |
| 0.3.0 | Partial converse compiled: `realise_small` (a witness whose unfired senders total at most B is realised) and `realise_pair` (a witness with two unfired senders is realised), with the corollary `bad_of_small_or_pair_witness`; together they settle 492,524 of 496,470 witness instances in the exhaustive range. Optional C searches extend the counterexample search (to B <= 30 at k <= 7, k <= 12 at B <= 14, random to B = 100) and check a one-step lemma that would imply the conjecture. |
| 0.4.0 | Verified residue decider: the (residue, smallest-unfired) pair table is proved exact for the witness condition (`spec_iff`, `dpWitness_iff`), its array-memoised implementation equal (`dpFast_eq`), and a false answer a safety certificate (`safe_of_dpFast`); a kernel-checked instance (`safe_2_3_3`); a Python mirror gated on the exhaustive range. |
| 0.5.0 | Certified three-way classifier: `stuck_of_oversize` (a bundle larger than B forces a stuck run), `bad_of_dpBad` (one- and two-sender witnesses, checked in O(k^2)), `classify_safe` and `classify_bad`; kernel-checked `bad_2_2_3_3_3`; the mirror's verdicts on the exhaustive range are safe 3,991 / bad 490,329 / unknown 6,141, never wrong. |
