# Revision 0.12.0 — kernel-certified verdicts for instances given as files

With the verified decider of 0.11.0, a concrete instance's verdict no longer
needs simulation. It can be a **theorem checked by the kernel**.
`verification/decoder/decode.py` reads a weighted digraph in a declared JSON
format (vertices, sink, arcs with multiplicities, capacities) and validates it,
failing closed. It then emits a Lean module in which:
- `outdegree` is computed in Lean from the arcs, so it is faithful by
  construction;
- the verdict is a theorem, `TerminalStable mult outdegree capacity` or its
  negation, obtained from `terminalStable_iff_decide` and a `decide` proof of the
  decider's output;
- Lean's own evaluation of the emitted lists must reconstruct the input.

Arbitrary digraphs are accepted, because the characterization needs no order.

## Test (`verification/decoder/check_decoder.py`, `evidence/decoder_check.json`)

| check | result |
|---|---|
| random instances, 2–5 vertices, multiplicities ≤ 2, cycles allowed, one Lean run | **80 of 80** verdicts kernel-checked, round trips exact |
| terminally stable / not | 27 / 53 |
| kernel verdict vs **simulated** transfer (instances with ≤ 3 vertices) | 42 of 42 agree |
| claiming the wrong verdict | **rejected by the kernel** |
| dropping an arc (consistent, so Lean accepts) | **rejected by the round trip** |
| axioms of every verdict theorem | `propext, Classical.choice, Quot.sound` |

This is the weighted counterpart of the checked decoder in
`CBMD-DYN-CAPACITY-FIRING-001` revision 0.2.0, with two differences. It works
on arbitrary digraphs. And it certifies negative verdicts as well as positive
ones.
