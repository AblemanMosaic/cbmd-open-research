# Revision 0.12.2 — fail-closed Lean-backed gates

This revision changes the qualification contract, not the mathematical
statement or its evidence.

`WEIGHTED_LEAN_DECIDER` and `WEIGHTED_KERNEL_CERTIFIED_INSTANCES` were marked
optional. Consequently their failures, including failure caused by a missing
Lean toolchain, did not fail aggregate full qualification. Both gates are now
required. The `--repository-only` scope remains the supported dependency-free
route.

The first clean CI run exposed an unconfigured Elan proxy on `PATH`. Both
runners now prefer the explicit override and exact Elan 4.35.0 installation
before consulting `PATH`, so temporary build directories retain the pin.

No theorem, finite count, source file, or retained evidence receipt changed.
