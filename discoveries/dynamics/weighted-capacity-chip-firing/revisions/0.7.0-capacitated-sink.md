# Revision 0.7.0 — a capacitated sink collapses the theory

Since revision 0.1.0 the dossier has listed **non-absorbing sinks** as out of
scope. This revision settles the question, and the answer is negative in the
strongest form available.

## Model

The sink holds chips under a finite capacity `sinkCap`. A firing of `v` is
capacity-legal when `v` is unstable, every receiver stays within capacity, and
`sink + toSink v ≤ sinkCap`. Ordinary firing keeps the absorbing sink, so
ordinary normal forms still exist and *transfer* means the same as before:
every capacity-terminal state reachable from an initial state is that state's
ordinary normal form.

## Result

At **every** finite sink capacity:

```
transfer  ⟺  no vertex is live      (C(v) < d(v) for every v)
```

and the right-hand side makes transfer trivial: nothing can ever fire.

**Why.** Every vertex sends at least one chip somewhere capacitated — to a
neighbour or, now, to the sink. So the all-full state (every vertex at
capacity, the sink at its cap) blocks every firing. If some vertex is live,
that state is not ordinarily stable, hence not the ordinary normal form of
itself. The witness is built from the capacities alone, so neither enlarging
vertex capacities nor enlarging the sink capacity avoids it.

This is the chip-firing face of the all-full obstruction of
`CBMD-CON-CAPACITY-PRESERVATION-001` (revision 0.2.0 there: a net in which every
transition increases some place preserves only if inert). The absorbing sink is
precisely what exempts chip-firing from it: a firing into an absorbing sink
need not increase any capacitated coordinate.

## Compiled (`SinkCollapse.lean`)

| declaration | content | axioms |
|---|---|---|
| `CappedSink.allFull_terminal` | under `Sends`, the all-full state is capacity-terminal | `propext, Quot.sound` |
| `CappedSink.capped_sink_breaks_transfer` | under `Sends`, a live vertex makes the all-full state admissible, terminal, and not ordinarily stable | `propext, Quot.sound` |
| `CappedSink.no_live_all_stable` | with no live vertex every admissible state is ordinarily stable | none |

The module is self-contained: it does not reuse `Core.lean`'s structures, since
those have no sink coordinate. `Sends` — every vertex sends a positive number
of chips somewhere — is the only hypothesis, and it holds of every system the
census generates (outdegree is positive there).

## Census (`verification/reference/sink_collapse.py`)

Sink capacities 0, 1, 2, 4; `n ≤ 3`, multiplicity ≤ 2, sink multiplicity ≤ 1,
vertex capacities up to `d(v) + 1`. See `evidence/sink_collapse_n3.json`.

Content gates, each required:

* zero disagreements between capped-sink transfer and "no vertex live";
* both populations non-empty;
* **bridge** — `Sends` holds of every generated system;
* **witness** — the Lean conclusion itself is checked directly: for every live
  system and every sink capacity, the all-full state is capacity-terminal and
  not ordinarily stable;
* **cap not idle** — some systems transfer with the absorbing sink and fail at
  every finite cap. Without these the result would only restate failures the
  absorbing theory already had.

## What this does not say

Nothing about sinks that *leak* (absorb above a threshold, or drain over time):
those are different models. The absorbing sink is the limit of the capacitated
one as `sinkCap → ∞`; no finite stage of the limit supports the theory, but the
limit does — that is the content of revisions 0.1.0–0.5.0.
