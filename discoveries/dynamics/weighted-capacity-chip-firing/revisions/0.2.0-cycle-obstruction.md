# Revision 0.2.0 — the ordered hypothesis is necessary and unrescuable

Version 0.1.0 listed cyclic graphs as out of scope. They are now resolved, in
the negative and completely.

> **Cycle obstruction.** If the nonsink arc relation contains a directed cycle
> and `C(v) >= d(v)` on it, fill every cycle vertex to its capacity and empty
> every other vertex. Each cycle vertex is blocked by its successor, which is
> full; each other vertex is empty and therefore ordinarily stable. The state is
> capacity-terminal but not ordinarily stable, so transfer fails.

The construction uses the capacities themselves, so it survives every
enlargement: there is no capacity function, however large, that restores
preservation once a cycle is present. This is stronger than the predecessor
dossier's single cycle witness, which showed failure at one capacity.

A directed cycle is formalized as a nonempty vertex set closed under a successor
map along positive-multiplicity arcs; on a finite vertex type that is equivalent
to containing a directed cycle. `ordered_has_no_closed_set` proves a forward
ordering excludes such a set, so the two results partition the model:

| arc relation | status |
|---|---|
| forward-ordered | preservation holds at `d(v) + b(v) <= C(v) + 1`, and that bound is sharp |
| contains a directed cycle | preservation fails at every capacity with `C(v) >= d(v)` |

Finite corroboration: the predicted witness is capacity-terminal and ordinarily
unstable in all 27,440 tested (cyclic graph, capacity) pairs, with zero
exceptions; and an exhaustive state sweep found **no** cyclic system preserving
transfer at any capacity slack from 0 to 4.

Both statements compile; `cycle_defeats_every_capacity` depends on
`[propext, Classical.choice, Quot.sound]` and `ordered_has_no_closed_set` on
`[propext]` alone.
