# Revision 0.9.0 — the characterization, assembled into one compiled equivalence

Revisions 0.3.0–0.8.0 proved every piece of the live-set characterization:
sufficiency (`wf_terminal_implies_ordinary_stable`), necessity of live-closure
and of the bound (by explicit witnesses), the equivalence of well-foundedness
with the absence of filled sets, and finally that a finite acyclic relation is
well founded. They were never assembled. So the claim record still said "the
exactness of the full three-condition predicate over the enumerated box remains
a finite census result". `Iff.lean` assembles them:

```lean
theorem terminalStable_iff (pos : ∀ u, 0 < outdegree u) :
    TerminalStable mult outdegree capacity ↔
      WellFounded (LiveArc mult outdegree capacity) ∧ LiveClosed .. ∧ LiveBound ..

theorem terminalStable_iff_acyclic (pos : ∀ u, 0 < outdegree u) :
    TerminalStable .. ↔ (∀ x, ¬ TransGen (LiveArc ..) x x) ∧ LiveClosed .. ∧ LiveBound ..
```

`TerminalStable` means that every admissible capacity-terminal state is
ordinarily stable. This is exactly what the sufficiency theorem concludes and
what every obstruction refutes. Only positive outdegree is assumed.

## The assembly

* **Live-closure** first: a live vertex with an arc to a dead one gives
  `liveToDeadFilledSet`, and a filled set refutes terminal stability
  (`not_terminalStable_of_filled`).
* **Well-foundedness** next, through `wellFounded_iff_no_filled_set`, which
  needs live-closure. This order matters.
* **The bound** last. For distinct endpoints it follows from the 0.4.0 witness
  `bound_violation_defeats_transfer`. A live self-loop needs no witness: it is a
  `LiveArc` cycle of length one, which well-foundedness already excludes. This
  case had no counterpart in the prose.
* **Sufficiency** is the 0.5.0 theorem, unchanged.

Axioms: `[propext, Classical.choice, Quot.sound]`.

## What the census measured, and how it relates

The census measured **transfer**: every capacity-terminal state *reachable*
from an initial state is that state's ordinary normal form. Terminal stability
implies transfer under the ordinary-theory hypotheses this dossier takes
explicitly (termination and uniqueness of ordinary stabilization). Every
obstruction above is an admissible state, reachable from itself, that refutes
transfer as well. So the census and the compiled equivalence describe the same
boundary. Transfer itself still rests on those explicit ordinary hypotheses,
as before.
