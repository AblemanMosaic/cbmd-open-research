# Explorer

No interactive explorer. The C++ tools in `verification/reference/` search the
two-colour process:

- `col_rand.cpp`: random search, binary tree;
- `colk.cpp`: random search, `k`-ary;
- `colk_ex.cpp`: exhaustive search, `k`-ary;
- `colour_exhaustive_binary.cpp`: exhaustive search, binary, all thresholds;
- `col_find_v.cpp`: a violation at a chosen vertex.
