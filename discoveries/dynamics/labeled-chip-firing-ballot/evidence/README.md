# Evidence

| File | Contents |
|---|---|
| `check_ballot.json` | Certificate replays (legal, stable, violating), the threshold equivalence, the exhaustive positive cases, and a control. |
| `colour_exhaustive_binary_l5.json` | Exhaustive two-colour search at 31 chips for thresholds 1–12. It gives the number of reachable states, the stable coloured states and the violating ones; violations start at `t = 8`. |
| `colour_census_l5.json` | All thresholds at 31 chips: reachable colour states, stable states, violating states; the forced order relations and their Hasse diagram. |
