# Revision 0.2.0 — checked decoding of external graph instances

The compiled theorem `fd_c1_concrete` takes the edge relation and the
outdegree function as parameters. Since 0.1.0 the dossier has recorded that
"external graph files are not decoded or certified by the Lean theorem; callers
must supply the true edge relation and outdegree function". This revision
closes that for a declared file format.

## The decoder (`verification/decoder/decode.py`)

Input: JSON with `vertices`, `sink`, unit `edges` (edges into the sink allowed)
and nonsink `capacity`. The decoder:

1. **validates**, failing closed with a named refusal: unknown name, loop,
   repeated edge, edge out of the sink, missing capacity, nonsink cycle, a
   vertex with no out-edge, capacity below outdegree;
2. **relabels** the nonsink vertices in a deterministic topological order;
3. **emits** a Lean module. In it, `edge` comes from an explicit list, and
   `outdegree` is defined as the number of nonsink out-edges plus the sink
   edges, so it is faithful to `edge` by construction. The three hypotheses of
   `fd_c1_concrete` are proved by **`decide`**, and the instance theorem
   `transfer` is stated and proved;
4. **round-trips**: Lean evaluates the emitted definitions itself, and the
   decoding is accepted only if that output reconstructs the input exactly,
   including each vertex's true outdegree.

The decoder's own checks are a convenience. The kernel's `decide` and Lean's
own evaluation are the certificate.

## Test (`verification/decoder/check_decoder.py`, `evidence/decoder_check.json`)

| check | result |
|---|---|
| random instances, 2–8 vertices, input naming not topological, decoded in one Lean run | **61 of 61 certified** |
| malformed inputs refused with the expected code | 7 of 7 |
| capacity below outdegree, emitted bypassing validation | **rejected by Lean** |
| an edge reversed against the order, emitted bypassing validation | **rejected by Lean** |
| an edge silently dropped (internally consistent, so Lean accepts) | **rejected by the round trip** |
| axioms of every instance theorem | `propext, Classical.choice, Quot.sound` |

The three controls are what make the certificate non-vacuous. The first two
show that the `decide` proofs really check the hypotheses. The third shows
that the round trip catches an unfaithful decoding that the kernel cannot see.

The Lean library is built in a private copy outside the checkout, keyed by
the hash of the sources, so the decoder leaves no build artefact in the public
tree. The pinned toolchain is taken from `$CBMD_LEAN_BIN` or `PATH`.

## Scope

Only the declared JSON format. Another format needs its own decoder in front of
this one; the emitted Lean and the round trip are format-independent.
