# Revision 0.2.0 — standalone verifier, and a second degeneracy trap

The standing obligation was to import a neutral standalone verifier exercising
non-degenerate off-diagonal contributors. `verification/owner_fiber.py` does
that, importing nothing from the archive.

Two degeneracy traps are now on record.

**The known one.** With `A = 0` and `R >= |D(u)|` every off-diagonal source row
vanishes identically, so the unique-contributor claim is vacuously true. The
verifier confirms this regime still reproduces as diagonal-only and refuses to
run its checks there.

**A new one, found while writing the verifier.** A parameter box can be
non-degenerate — off-diagonal rows exist and are nonzero — while the generated
*layouts* still contain no off-diagonal contributor. If every owner's head word
equals the target's own head, the only orbit element carrying that head is the
target itself, so every fiber is diagonal. The first draft reported
`offdiagonal_contributors: 0` against 8 available nonzero off-diagonal rows, and
the gate caught it.

The lesson generalizes beyond this dossier: a non-degenerate *object* does not
imply a non-degenerate *test population*. Both need their own control.

Results after the fix, at `Q = 2, r = 2, A = 1, R = 2` with head-covering owners
and one duplicated head:

| check | scope | outcome |
|---|---|---|
| U1 unique contributor | 480 fibers, 48 off-diagonal contributors | 0 violations; 144 single-contributor fibers, candidate lookup agrees 144/144 |
| U1 breadth | `Q = 3`, 1,728 fibers, 288 off-diagonal | 0 violations, 0 candidate mismatches |
| U2 class-count bound | 1,230 target sums | 0 violations; bound attained 54 times |
| U3 active coherence | adverse control | two contributors at target `(0,0|1,1)` with coherence broken at active coordinate 0 |
