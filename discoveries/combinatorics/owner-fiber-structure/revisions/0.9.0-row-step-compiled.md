# Revision 0.9.0 — the row-level step, compiled

Revision 0.7.0 split the support-in-orbit hypothesis into two parts:
- an amplitude part, already compiled natively as
  `entry_eq_zero_of_not_inOrbit` in `proofs/native`;
- a row-level step: the source row is the indicator at `y = u` plus a term
  that is a multiple of the amplitude.

`Rows.lean` compiles the second part, for any coefficient type:

```lean
theorem row_support_in_orbit
    (row_form : ∀ u y, y ≠ u → amp u y = 0 → row u y = 0)
    (amp_support : ∀ u y, amp u y ≠ 0 → InOrbit u y) :
    ∀ u y, row u y ≠ 0 → InOrbit u y
```

`row_form` is the shape of the reference row. The standalone verifier now
checks it on its model: no off-diagonal row is nonzero when the amplitude term
is zero, over 1,536 rows. It also gates that the check met 120 pairs with a
nonzero amplitude, so the gate is not vacuous.

## What remains

`amp_support` is compiled natively for `LayoutNumerator.entry`. The only
missing link is the binding of this dossier's `Typ`/`InOrbit` to the native
`UniversalType`/`InOrbit`, across two toolchains, together with coherence,
which belongs to the packing source. `SOURCE_BOUND_COMPILED` stays withdrawn.
