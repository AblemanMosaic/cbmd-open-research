# Review status

No specialist review is recorded.

The classical ingredients have now been assessed in
[`PRIOR_ART.md`](PRIOR_ART.md): the object is the binary Krawtchouk polynomial
at a negative argument, the centered vanishing is a published root fact, the
coefficient-extraction form is Newton interpolation with Vandermonde
convolution, and the claim that orthogonality is available has been withdrawn
because the measure does not exist at these parameters.

The source-specific identification -- whether the reference amplitude is read
correctly off the source conventions -- is a separate question and still needs
the archive.
