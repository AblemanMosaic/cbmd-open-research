# 0.4.0 candidate — inactive cancellation and guarded count

Two additional no-escape components now compile against fully hashed local import closures.

First, if any coordinate in an ordered difference is inactive in the source state, its singleton swap fixes every point in the source swap orbit. Commutativity of coordinate swaps then makes the entire ordered difference zero. This proves inactive-coordinate cancellation at the native operator level rather than only in the finite reference model.

Second, the number of `j`-element active subsets containing every mismatch other than the pivot is exactly the guarded binomial term. The explicit guard is necessary for the natural-subtraction defect recorded in 0.2.0.

The remaining theorem is not yet assembled. It still requires a proof that native delta selects exactly the active subword `mismatches.erase t`, with the expected sign.
