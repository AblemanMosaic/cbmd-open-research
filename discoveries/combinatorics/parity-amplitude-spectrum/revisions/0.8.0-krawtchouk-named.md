# Revision 0.8.0 — the classical object, named precisely, and one word withdrawn

The standing obligation asked for a targeted prior-art assessment. It has been
run, its outcome is deflationary, and it corrects a term that was claiming an
availability the parameters do not support.

## What the object is

With the MacWilliams–Sloane binary Krawtchouk polynomial in an **indeterminate**
argument, `K_k(x; n) = Σ_j (−1)^j C(x, j) C(n − x, k − j)`,

```
n(A, R, delta, f) = 2^(R−1) · (−1)^A · K_d(−A; R − delta),   d = R − 1 − f.
```

Exponents match as `n − x = A + R − delta` and `x = −A`, so the length is
`n = R − delta`. Checked on 6,048 classes with no mismatch.

This is a **naming observation, not a theorem**. Writing
`C(−A, j) = (−1)^j C(A+j−1, j)` cancels the sign and turns the Krawtchouk sum
into this dossier's own convolution in a line. The name earns its place by
saying which classical facts apply.

## The word withdrawn

The README said the identification *"reduces to classical Krawtchouk symmetry
and orthogonality"*. Orthogonality does not exist here.

Krawtchouk orthogonality sums over `i = 0 … n` against a binomial weight and
needs `n` a non-negative integer with the arguments inside that range. The
argument here is `x = −A`, outside it; the length `n = R − delta` can be
negative. There is no measure, so nothing can rest on orthogonality, and the
phrase has been corrected to **symmetry** alone.

What survives — the generating function and the `q = 2` reflection law — are
polynomial identities in the exponents, valid by the binomial series with no
analytic continuation required. The nearest genuinely two-free-exponent family
is Meixner rather than any "negative-parameter Krawtchouk"; Krawtchouk is its
degenerate point `c = −1`.

## Centered vanishing, placed

The centered vanishing reads as a parity remark — on `delta = 2A + R` the
generating function is `(1 − y²)^(−A)`, which is even. True, and also
classical under its proper name: for `q = 2`, `K_m(n − x) = (−1)^m K_m(x)`, so
`n/2` is a root for odd `m` (Coleman, arXiv:1101.1798, Lemma 5.1 and Prop 5.2).
On the centered line `n = R − delta = −2A` and `x = −A`, which is `n/2`
**exactly**. The even values `C(A + e − 1, e)` are the central coefficients.

So the statement is a published root fact, not only an observation about an
even series. It should be cited, not claimed.

[`verification/krawtchouk_identification.py`](../verification/krawtchouk_identification.py),
standard library only:

| check | result |
|---|---|
| amplitude equals `2^(R−1)(−1)^A K_d(−A; R−delta)` | 6,048 checked, **0** mismatches |
| closed form equals the defining Newton construction | 2,352 checked, **0** mismatches |
| binary reflection law `K_m(n−x) = (−1)^m K_m(x)` | 6,048 checked, **0** mismatches |
| centred line: `n = −2A`, argument is `n/2` | 288 checked, **0** mismatches |
| odd degrees vanishing there | 128 |
| even degrees non-zero there | 148 |

The last two rows are the anti-vacuity controls: a centred-line check in which
no odd degree occurred, or in which the even values were all zero, would be
confirming nothing.

Orthogonality is deliberately **not** checked, because it is not well posed at
these parameters. That absence is the point of the revision.
