# 0.2.0 candidate — closed-form correction

The first source-transport formula was false as stated. This is a correction to an intermediate bridge, not a refutation of the centered-vanishing claim itself.

Let `m = |mismatches i u y|`. The original Lean expression used

```text
choose(|D|-m, j-(m-1))
```

with natural-number subtraction. When `j < m-1`, Lean evaluates `j-(m-1)` to `0`, so the expression contributes `choose(|D|-m,0)=1` instead of contributing zero.

The exact native counterexample has `Q=2`, `A=0`, `R=1`, both coordinates active, `y=u`, and `t=0`. It satisfies orbit membership and `t ∈ mismatches`. The pinned `entry` definition evaluates to `0`; the proposed right side evaluates to `-1`. The no-escape Lean proof is in `verification/lean/EntryClosedFormCounterexample.lean`.

The corrected candidate explicitly makes the summand zero when `j < m-1`. It passed 134,370 licensed binary comparisons, with 32,128 active-cardinality mutant detections and 70,722 sign-mutant detections. This finite evidence is not a general proof. The corrected source theorem remains the next formal obligation.
