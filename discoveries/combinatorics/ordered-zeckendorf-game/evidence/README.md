# Evidence

| File | Contents |
|---|---|
| `lgs_constant.json` | Gates for `n ≤ 600`: count model against direct simulation, no merges in the pile phase, free upper splits, the step lemma, the invariant, the exact identity, the density, a window and a control. |
| `lgs_large.json` | `L_LGS(n)` from the C counter for `n = 10³ … 10⁹`, and `(n²/2 − L)/n − (φ/√5) log_φ n`, with the output's SHA-256. |
| `lgs_optimal_small.json` | Exhaustive maximal length versus the LGS length for `n ≤ 16` (all equal). |
| `lgs_optimal_exhaustive_24.json` | C++ exhaustive search: maximal length equals the LGS length for every `n ≤ 24`. |
