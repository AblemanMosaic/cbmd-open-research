# Reference tools

| File | Role |
|---|---|
| `check_cayley_jacobian.py` | Required gate (about 1 s; needs sympy). |
| `cayley_jac.py` | Exact Smith normal form of the reduced Laplacian; exhaustive scan `cayley_jac.py MAXORDER MAXSIZE`. |
| `check_bound.py` | Product formula and the quantitative bounds on all scanned cases. |
| `check_norms.py` | Exact cyclotomic norms (resultants) for cyclic groups. |
| `normscan.py` | Norms of sums of terms `1 − ζ^x` modulo prime powers. |
| `nonabelian_examples.py` | Critical groups for the 3-dimensional rotation representations of `A_4`, `S_4` and `A_5` (Smith normal form, needs sympy). |
