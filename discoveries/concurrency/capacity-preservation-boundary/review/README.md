# Review

No external review. The targeted comparison still owed: whether the condition
for a place capacity to introduce no new dead markings is known in the
bounded-Petri-net literature. The nearest named notions are **implicit places**
(capacities that never restrict firing — strictly stronger than what is studied
here, and the trivially sufficient case this census confirms) and
**non-blockingness** of bounded nets, which is a reachability property rather
than a structural condition on capacities. Neither is the statement examined
here.
