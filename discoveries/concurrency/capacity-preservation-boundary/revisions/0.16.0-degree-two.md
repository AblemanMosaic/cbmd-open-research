# Revision 0.16.0 — two consumers per place suffice for hardness

Revision 0.12.0 made one structural parameter sharp. With no place having two
consumers (and input places everywhere), the problem is polynomial; one such
place makes it coNP-complete. But the hard nets of 0.10.0 concentrate all the
conflict on that one place `g`, which has **unboundedly many** consumers. This
revision bounds the other parameter. Hardness already holds when **every place
has at most two consumers**, the net is strict free-choice, every capacity is
1, and every transition has one or two input places.

## The construction

Split `g` into copies `g_0, …, g_{L−1}`, `L = n + K`, one per transition that
read `g`. Join them by a **cyclic** chain of copiers `g_j → g_{(j+1) mod L}`. A
copier has `g_j` as its only input and `g_{j+1}` as its only output. So it is
ordinarily enabled as soon as `g_j` holds, and can be capacity-blocked only by
`g_{j+1}` already holding. In a bad marking, therefore, one copy holding forces
all of them. Each copy is read by its user and by one copier: two consumers.

**The cycle is essential, and the census found that out.** The first draft
used an open chain `g_0 → … → g_{L−1}`. A bad marking can then switch on a
suffix of the chain only, leaving the clauses read by earlier copies
unconstrained. The census gave wrong verdicts until the chain was closed. The
`open` ablation keeps that failure on record.

## Compiled (`DegreeTwo.lean`)

| declaration | content |
|---|---|
| `consumer_shape`, `at_most_two_consumers` | every place has at most two consumers |
| `free_choice` | a shared place is the sole input of each of its consumers |
| `satisfiable_of_bad` | a bad marking yields a satisfying assignment: one copy holds, the copier chain passes it round the cycle (`Nat.mod_add_mod`), and the clause users then overflow on true literals |
| **`degreeTwo_preserves_iff_unsatisfiable`** | for `2 ≤ n + K`, the net preserves exactly when the CNF is unsatisfiable |

Axioms at most `[propext, Classical.choice, Quot.sound]`. `2 ≤ n + K` rules out a
copier that is a self-loop, which would never be blocked.

## Where the line now sits

| maximum consumers per place | status (every transition with an input place) |
|---|---|
| 1 | polynomial (0.12.0; compiled decider 0.15.0) |
| 2 | **coNP-complete** (reduction compiled) |

The boundary is sharp in both conflict parameters. One place with unboundedly
many consumers suffices, and so do many places with two consumers each.
