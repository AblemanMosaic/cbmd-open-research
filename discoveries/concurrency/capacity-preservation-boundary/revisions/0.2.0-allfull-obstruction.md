# Revision 0.2.0 — one region of the boundary proved, not censused

Version 0.1.0 mapped where the chip-firing live-set characterization transfers
and where it stops, entirely by exhaustive census over small boxes. This turns
one region of that map into a theorem.

## The statement

Call a net **increasing** when every transition strictly increases the token
count at some place, and **inert** at a capacity vector `C` when no transition
can ever fire inside the box — that is, for every `t` there is a `q` with
`C(q) < pre(t, q)`.

> **Theorem.** For an increasing net,
> `PRESERVES(N, C)  ⟺  N is inert at C`.

So an increasing net is either completely frozen or it has a deadlock the
capacity invented. There is no third case, and no middle ground to engineer.

## The proof, in one marking

Take the all-full marking `m = C`, which is admissible.

*It is capacity-dead.* For any transition `t`, pick the place `q` where `t`
strictly increases. If `t` is not ordinarily enabled at `C`, it is not capacity
enabled either. If it is, then `pre(t,q) ≤ C(q)` and firing leaves
`C(q) − pre(t,q) + post(t,q) > C(q)`, which the capacity refuses.

*It is ordinarily enabled whenever the net is not inert.* If some `t₀` has
`pre(t₀,q) ≤ C(q)` at every `q`, then `t₀` is ordinarily enabled at `C`.

Those two together break preservation. Conversely, if the net is inert, no
admissible marking ordinarily enables anything, so preservation holds vacuously.

Because the witness is built from the capacities themselves, raising capacities
does not escape it — the same argument runs again at the new all-full marking.
This is the same shape as the filled-set obstruction of
`CBMD-DYN-WEIGHTED-CAPACITY-001`, with the filled set taken to be every place.

## Why chip-firing is not covered, and why that is the point

A chip-firing vertex's transition consumes `d(v)` chips from `v` and adds
`m(v,w)` to each out-neighbour `w`, so it strictly increases a place — **unless**
the receiver is the absorbing sink, which carries no capacity. The absorbing
sink is exactly what keeps chip-firing out of this theorem's hypothesis. Read
the other way round: the sink is not a modelling convenience in that dossier,
it is the only thing standing between the model and total collapse.

The hypothesis is checked to be load-bearing rather than assumed to be: outside
the increasing class the conclusion is wrong on 39,464 nets in the measured
boxes, every one of them with a draining transition.

| `increasing_preserves_iff_inert` | `propext, Quot.sound` |
| `increasing_firing_breaks_preservation` | `propext, Quot.sound` |

`Classical.choice` is not used anywhere.

`preserves_iff_reachable_form` deserves a word. The census quantifies over
markings capacity-reachable from an admissible initial marking; the Lean
statement quantifies over admissible markings. Those are the same set — capacity
firing cannot leave the box, and every admissible marking is reachable from
itself — but that is a claim about the model rather than about the mathematics,
and it is exactly the sort of step that quietly goes wrong, so it is proved
instead of noted.

## Evidence and its gates

[`verification/allfull.py`](../verification/allfull.py) measures two
populations, because the theorem is interesting only if both are non-empty:

| | count |
|---|---|
| nets inside the increasing class | 37,197 |
| disagreements with the equivalence | **0** |
| of the class, nets that are **not** inert | 25,586 |
| nets outside the class where the conclusion would be wrong | 39,464 |

The second row alone would be worth nothing. The third is what gives it
content: those 25,586 nets are ones the theorem says all fail, and if the class
had contained only inert nets the agreement would have been an artefact of an
empty test. The fourth is the control on the hypothesis itself.

A defect caught here, recorded because this dossier's value is in its controls:
the first draft of the census compared `preserves(...)` — which returns a
`(verdict, witness)` pair in this dossier's own model — directly against a
boolean, so every case "disagreed". The gate that requires zero disagreements
failed loudly instead of the usual silent pass, and the comparison was fixed.
Counts afterwards match a separately written scratch implementation exactly.
