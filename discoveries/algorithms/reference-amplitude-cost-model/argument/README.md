# Argument map

`COST_THEOREM.md` proves and measures the bounded integer-amplitude comparison under BCM-1. `ALGORITHMIC_EFFICIENCY.md` separates the spectrum-table result from row assembly, corrects the enumeration count to a per-amplitude scope, and states every required ring unit.

The executable replay lives in `../verification/reference-model/`. These documents establish a result about the frozen reference producer only; they do not bind a native executable entry or establish a native total-cost theorem.
