# Scope and parameter-regime correction

Date: 2026-10-28.

The frozen reference argument remains hash-bound to its source archive. Its Section 5 phrase "exponentially cheaper in Q" requires a stated joint parameter regime. At fixed R >= 1,

```text
sum_{j<R} binom(Q-1,j) 2^j
```

is polynomial in Q, with degree R-1 (constant for R=1). Comparing it with an O(R) scalar arithmetic route does not uniformly establish exponential savings in Q. Exponential behavior must be demonstrated for a specified growing-R regime, and arithmetic operation counts are separate from bit cost and wall-clock time.

The reference checker still evaluates the reference model. Later local source correspondence, kernel counts and the total joint realization are tracked as [a separate successor line](../../native-joint-realization/README.md). The existing source copies are preserved byte for byte; this revision controls the current interpretation of their cost language.
