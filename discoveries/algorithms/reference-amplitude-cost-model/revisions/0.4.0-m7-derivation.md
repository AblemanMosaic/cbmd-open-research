`argument/M7_DERIVATION.md` derives B5-M7 from the Python producer's definition
in four steps:
1. an indicator collapse showing the amplitude depends only on `(δ, f)`;
2. an inner-sum collapse;
3. the parity coefficients in closed form, by Newton's formula and Vandermonde;
4. a binomial identity proved by the substitution `x = z/(1+z)`.

`verification/independent/derive_m7.py` checks each step separately, with
code written from the definitions and no imports from the frozen source except
in a final, labelled cross-check. It also requires two mutated statements to
fail. All steps are exact on their boxes (689,730 + 23,766 indicator cases;
380,464 amplitudes; 49 parity systems; 3,132 identity cases).

This addresses the unresolved item *standalone separately implemented
verifier*: the checker is standalone and separately written. It is not
externally authored, so *external mathematical review* stays open.

The pinned reference-model members are unchanged.
